Quando a empresa se cadastra:

assinatura.situacao = TRIAL
assinatura.recorrencia = MENSAL ou ANUAL
assinatura.trial_termina_em = data atual + 7 dias
assinatura.proximo_vencimento = trial_termina_em
assinatura.valor = valor do plano

Quando cliente confirma pagamento ou contrata:

assinatura.situacao = ATIVA
assinatura.proximo_vencimento = próximo mês ou próximo ano

E gera registro em:

assinatura_cobranca.situacao = ABERTA

Quando pagar:

assinatura_cobranca.situacao = PAGA
assinatura_cobranca.pago_em = NOW()

E atualiza a assinatura:

assinatura.situacao = ATIVA
assinatura.proximo_vencimento = próximo vencimento

Se passou do vencimento e não pagou:

assinatura.situacao = VENCIDA
assinatura_cobranca.situacao = VENCIDA

Depois de uma regra de bloqueio:

assinatura.situacao = BLOQUEADA
