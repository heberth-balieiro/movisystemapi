//// Git ///////////////////////////////////////////

Enviar alterações

git init
git branch -M main
git remote add origin https://github.com/heberth-balieiro/easycatalogo-backend.git
git add .
git commit -m "Melhorias de codigo e criação de tabelas da API Easy Catálogo"
git push -u origin main

Enviar a força quando tem arquivo diferente

git remote set-url origin https://github.com/heberth-balieiro/easycatalogo-backend.git
git branch -M main
git add .
git commit -m "Reenvio completo da API Easy Catálogo"
git push -u origin main --force

Baixar as alterações do git

git remote set-url origin https://github.com/heberth-balieiro/easycatalogo-backend.git
git fetch origin
git checkout main
git reset --hard origin/main
git pull origin main
